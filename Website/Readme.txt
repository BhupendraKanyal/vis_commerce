This Github folder is for website for VisCommerce.com

This is Version #9

1-install node lts in your system 
2-clone .repo
3-open the terminal and check for npm -v(just to confirm npm is there)
4-after checking and cloning do npm i to the repo folder
5-to check locally do npm start
6-to deploy create a build and deploy that build with npm run build which will create a build folder for deployment we need to deploy only that folder
